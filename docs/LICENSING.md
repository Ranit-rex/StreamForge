# Licensing and third-party notices

StreamForge is intended to be free, open-source software.

## Android streaming dependency
The Android client currently depends on RootEncoder, which is published under Apache License 2.0. Preserve the upstream copyright and license notices in distributed builds.

## Android and browser dependencies
- AndroidX and Jetpack Compose: review their individual Apache-2.0 notices.
- Gradle plugins and transitive dependencies: generate and review a dependency attribution inventory before release.
- Browser PWA currently uses native browser APIs and has no bundled third-party JavaScript library.

This file is a project checklist, not legal advice. Add complete license texts and an automated third-party notices report before publishing release APKs.
